# Session Kickoff

When starting a new session on this project, do the following:

1. Read `CLAUDE.md` for project context and current status
2. Run `git status` and `git log --oneline -5` to see current branch and recent work
3. Run `gh issue list --state open` to see the backlog
4. Summarize the current state: what branch you're on, what's been done recently, what issues are open
5. Ask what to work on next, or suggest the next logical issue from the backlog

If resuming mid-issue, check for any failing tests with `make test` before continuing.
